# Carousel_Raytracing
Project for Unipi Computer Graphics course

This ray tracer renders a scene with cars driving along a track on a square terrain.
Initially the scene is viewed using the trackball camera that simulates zoom in and out by scaling the scene. 
You can change the camera with the Menu on the top left of the UI. The options are:

-a free camera you can move around the scene using keyboards

-the trackball camera

-any of the cameramen around the scene, which are numbered clockwise (camera 1 is on top right, camera 2 is bottom right ecc.)


free camera controls:

-W forward

-A left

-S back

-D right

-Q up

-E down

-Mouse Left and drag, rotates the camera
